# Config Domain DDL

## 1. 범위
- 전역 운영 설정 읽기/수정 API(민감값 마스킹 필요)
- 보안/도메인/알림/포인트 정책 값의 소스

### 2.2 핵심 포인트
- 전역 정책(`cf_*`)은 API `GET /config` 응답 시 민감 키(`cf_icode_pw`, 인증키, 토큰, API 비밀번호류)를 제외.
- 포인트 정책은 회원·게시글 기능(포인트 도메인)과 일관되게 합의 필요.

## 3. API 계약 영향
- 공통 설정 조회 API는 `SELECT *` 대신 화이트리스트 기반 반환.
- 업데이트 API는 감사 로그 기록을 권장.
