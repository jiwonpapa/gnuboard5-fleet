# G5 Admin Desktop

Tauri v2 기반의 Gnuboard5 관리자 데스크톱 앱입니다.

## Stack

- Tauri v2
- Rust
- React 19
- TypeScript strict
- Tailwind CSS 4
- Vitest

## Development

```bash
bun install
bun run lint
bun run test
bun run build
bun run tauri dev
```
